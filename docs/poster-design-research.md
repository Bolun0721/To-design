## 看到的共同结构

### 明日方舟（官网 / 档案 / 新闻）

- **近黑纸面**（约 `#191919`），不是纯黑；叠一层极淡点阵，像工业扫描底。
- **单一青色信号**（约 `#19D1FF`）只做分类、日期、当前项和短标签；白色大字承担标题。
- **巨大空心拉丁字**当背景（“DYNAMIC COMPILE”），被画面裁切，只留结构。
- **成对中英标签**：英文小号全大写 + 中文粗体；`//` 开头；日期用 `2026 // 11 / 17` 的斜杠格式。
- **1px 细线分区**，几乎不用卡片阴影；图片是硬边矩形，信息在细线里排。
- **真实编号 / 日期 / 计数**当装饰；右侧竖向索引（`// 04 / 05`）、底部灰色返回条。
- 档案页结构：图标 + 标题 + 分类 + 日期 + 细线 + 大图 + 侧栏动作按钮。

### 明日方舟：终末地（官网主视觉 / UI 规范）

- **白纸 / 浅灰场**为主，大面积留白；蓝（约 `#2B54FF`）与黄（`#FFFA00`）只做信号和短线。
- **超大中文标题**带白色错位描边 / 阴影，压在人物与场景上；标题周围有**点阵补丁、角标、细蓝线、技术注记**。
- **切角画框**：矩形照片切掉一到两个角，角上不压字；切角表示“可操作 / 被选中”的语法。
- **细线 + 端点**像电路图；小型 `//` 标签、数字、分段线、三色条（品红 / 黄 / 薄荷绿）只出现一两处。
- **等高线**极淡、不闭合，做地形 / 工业背景；不是装饰性网格纸。
- UI 规范 token：纸 `#F4F4F2`、板 `#FFFFFF`、墨 `#161616`、信号黄 `#FFFA00`、蓝 `#2B54FF`、品红 `#FF00F0`、薄荷 `#00E0A4`；圆角 0；45° 斜线填充；切角 7/8/26/52。

## 设计约束

- 只用一种信号色（每套模板内），只做填充 / 短线 / 小面积，不铺大面积黄。
- 切角只给照片框、标签、按钮式块；正文和文字不压切角。
- 英文标签全大写、加字距；中文用粗黑体；不用楷体 / 宋体 / 手写体。
- 所有编号、日期、时间、地点都来自用户内容或方案日期，不编造。
- 不使用官方字体、标志、图标、立绘、截图或文案；不把游戏 UI 原样搬进海报。
- 四套模板都必须适配无照片：图案配方（纸纹 / 网格 / 等高线 / 斜切）填充视觉区，文字层不变。
