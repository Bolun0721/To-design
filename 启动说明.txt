头版智造局 · 本地启动说明
==========================

1. 先把 ZIP 完整解压到一个普通文件夹。
   不要直接在压缩包里双击启动脚本。

2. 安装 Node.js 18 或更高版本：
   https://nodejs.org/
   安装时保持 "Add to PATH" 勾选。

3. 双击项目根目录的：
   启动项目.bat

   脚本会自动：
   - 检查 Node.js
   - 检查 5173 端口是否已有服务
   - 启动本地服务
   - 2 秒后打开 http://127.0.0.1:5173/

4. 启动窗口需要保持打开。
   关闭窗口 = 停止本地服务。

5. 只启动服务、不自动打开浏览器：
   启动项目.bat nobrowser

6. 项目不需要 npm install。
   Preact / htm / html2canvas 已放在 public/vendor/，
   6 款艺术英文字体已放在 public/fonts/。

7. 如果 Windows 提示安全警告：
   这是本地批处理脚本，可选择“仍要运行”。

8. 默认访问地址：
   http://127.0.0.1:5173/

9. 需要联网的只有模型 API 请求；
   没有 Key 时，可以点页面里的「载入示例，先看效果」。

10. 建议使用 Chrome / Edge 最新版。
